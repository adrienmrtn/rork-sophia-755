# コースの翻訳：フランス語から日本語へ

フランス語版（`content/courses/fr/`）が原典です。この文書は `content/courses/ja/` の仕様書で、
`scripts/check_course_translation.py --lang ja` が機械的に検査します。同じ規則がUI、クイズ、用語集、
カタログ、App Storeページ、規約類にも適用されます。必須の用語は `content/terminology/`
（`termes_produit.json`、`mots_pieges.json`、`oeuvres.json`、`sentinelles.json`）にまとめてあります。

## 1. 目指すもの

納品するのは「翻訳」ではなく、コースの**日本語版**です。日本語を母語とする編集者が同じメモから
書き下ろしたような文章で、読者がフランス語の原文を想像できてはいけません。優先順位は次のとおりです。

1. **正確。** 事実を曲げない、足さない、落とさない。日付は必ず確認する：`**18 juin 1815**` →
   `**1815年6月18日**`。
2. **自然。** 声に出して読んで引っかからない日本語。
3. **平易。** 短い文、日常の言葉。好奇心のある中高生がついてこられること。
4. **形式に忠実。** 文の数と論の運びはほぼ同じ。長さの目安は原文の文字数ではなく、読む時間で揃える。

**文体の決定（全員共通）。**

- **コース本文・クイズ・用語集の定義・UIの文はすべて「です・ます」調。** 学習アプリとして、
  丁寧すぎず冷たくもない調子にする。尊敬語・謙譲語の重ね（「〜させていただきます」「ご確認ください
  ませ」）は使わない。
- **見出し、ボタン、ラベル、タイムラインの項目名は体言止めか動詞の終止形・命令を避けた形**：
  `Commencer` → `はじめる`、`Ton parcours` → `学習ルート`、`TERMINÉE` → `完了`。
- 一つの段落の中で「だ・である」と「です・ます」を混ぜない。

**呼びかけ。** フランス語の `tu` は日本語では**主語を省略**して表す。「あなた」「君」「お前」は
使わない。`ton/ta/mon` も多くは訳さない（「自分の」を補うのは必要なときだけ）。

> 誤：`あなたのプロフィールを見る` · `あなたはスマホに何時間使っていますか？` · `私の試用を解除する`
> 正：`プロフィールを見る` · `スマホを1日に何時間使っていますか？` · `無料トライアルを始める`

**不定代名詞 `on` は「私たち」「彼ら」ではない。** 受け身や「〜とされる」「〜と言われる」、または
主語のない文にする。本当の `nous`（`notre façon de regarder`）だけ「私たちの」と訳してよい。

> 誤：`私たちは彼を殺したい。` · `彼らは、データは新しい石油だと言う。`
> 正：`彼は命を狙われます。` · `データは新しい石油だと言われます。`

**性別。** 「彼」「彼女」は日本語では目立つので多用しない。人物は名前か役割で繰り返す：
`Elle répond : « Personne ! »` → `エコーは「だれも！」と答えます。` 利用者の声の名前は訳さず
カタカナにし、学年と年齢は日本の形にする：`Inès, Terminale` → `イネス（高校3年）`、`Sarah, 26` →
`サラ（26歳）`。職業名は中立に：`scientifique` → `科学者`（「女性科学者」と書かない）。

**時制と直訳調。** 歴史的現在（`En 1874, ils organisent une exposition`）は「〜します」で自然に
訳せるが、一つの段落で過去と現在を行き来しない。直訳の型を避ける：`Voici comment tout a commencé.` →
`すべてはこうして始まりました。`（×「ここにすべてがどのように始まったかがあります」）。
`De la gravité à l'ADN` → `重力からDNAまで`。無生物主語の連発（「この発見は彼に〜を可能にした」）は
「この発見によって、彼は〜できるようになりました」に直す。

**見かけの意味にだまされる語。** 英語の意味ではなく、文脈のフランス語の意味で訳す：

| フランス語（意味） | 日本語 | 使わない |

| Gratuit; Expire dans; Mensuel / Annuel | 無料；`終了まで 02:59:59`；月額 / 年額 | フリー；期限切れ；月刊誌 |

## 2. 変えてはいけない骨格

訳すのはテキストのフィールドだけです。それ以外はツールがフランス語の骨格からコピーするので
触れない：`id`、`subject`、`subcategory`、`type`、`asset`、`image`、`ratio`、`free`。

| フィールド | 中身 | 注意 |
| --- | --- | --- |
| `title` / `subtitle` | タイトル / その下の一行 | 作品なら日本で定着した題名。年や期間（`1945-1975`）は残す。 |
| `description` / `hero.hook` | 2文の紹介 / つかみの一文 | 単独で読めること。散文ではなく宣伝文。 |
| `sections[].title` | 節の見出し | 名詞句、句点なし：`ジェノサイドと記憶：二度と繰り返さない`。 |
| `paragraph.text` | 本文 | 作業の中心。 |
| `image.caption` | 画像キャプション | 短く。句点は完全な文のときだけ。 |
| `funFact.text` / `takeaway.text` | 豆知識 / まとめ | 軽く、話しかけるように。覚えて帰ってほしいこと。 |
| `quote.text` / `quote.attribution` | 引用 / 発言者 | §6を参照。 |
| `timeline.events[].date` | `1789年`、`1940年6月`、`紀元前450年ごろ` | §8を参照。 |
| `timeline.events[].title` / `.detail` | 項目名 / 一文 | 項目名はごく短く、句点なし。 |

**プレースホルダーは一字も変えない**：`%@`、`%d`、`%1$@`、`%2$d`、`{n}`、`\n`。数も順序も原文と
同じにする。語順を変えたいときは位置指定（`%1$@`、`%2$@`）を使い、記号そのものは書き換えない。
プレースホルダーの前後に空白は入れない：`{n}日間の無料トライアルを始める`、`%d件のクイズ`。

## 3. インラインの記号

三つの記号を必ず残す：`**太字**`（段落が扱う日付、数、人名、作品）、`*斜体*`（本文中の作品名）、
`[[用語]]`（用語集の項目。タップすると定義が開く）。

- 記号は必ず対になる。`**` が奇数個なら誤り。
- 記号の内側に空白や句読点を入れない：`**1945年**、` は正しく、`**1945年、**` と `** 1945年 **` は誤り。
- 太字は日本語の対応部分にかける：`**30 000 mots**` → `**3万語**`。助詞は外に出す：`**ナポレオン**は`。
- 原文にない太字を足さない。文全体を太字にしない。
- 斜体は日本語では読みにくいので、作品名は記号の内側に『』を入れる：`*Les Fleurs du Mal*` →
  `*『悪の華』*`。記号を削って『』だけにしない（検査が記号の数を数えます）。
- 日本語では記号の前後に空白を入れない：`それが[[ジハード]]です。`（×`それが [[ジハード]] です。`）。

## 4. 用語集の項目：いちばん大事な規則

フランス語の `[[...]]` 一つにつき日本語の `[[...]]` がちょうど一つ。**文の中の、論の流れの同じ位置**に
置く。段落の末尾に用語を並べて済ませない。抜け落ちも同じ誤りです。

> 誤：`主に弱体化させた：十字軍が街を略奪した。[[コンスタンティノープル陥落]]`
> 正：`都市を決定的に弱らせたのは[[第4回十字軍によるコンスタンティノープル占領（1204年）]]で、西欧の
> 十字軍が街を略奪しました。`

用語の文字列は、そのコースの `ios/Sophia/Resources/Locales/glossary.ja.json` のキーそのものです。
登録されていないキーはただの死んだ文字になります。`scripts/make_translation_briefs.py` の指示書に
使えるキーが並んでいるので、一字一句そのまま使う。別の項目にすり替えない（`prix de transfert` に
`[[ビッグデータ]]` は誤り、正しくは `[[移転価格]]`）。登録キー自体が§5に反する場合（`ムハマド`、
`ヘジラ`）は、段落ごとに直さず `glossary.ja.json` でまとめて直す。

**キーは活用させない、何もくっつけない。** 日本語は助詞が独立しているので、文はキーの基本形
（名詞）の外側で組み立てる：

- 助詞・コピュラは `]]` の直後に空白なしで続ける：`[[ジハード]]は`、`[[取り付け騒ぎ]]が起きます`、
  `[[移転価格]]です`。
- キーの中に助詞を入れない、キーに語尾を足さない：`[[ジハードの]]`、`[[産業革命]]的な`、
  `[[自由放任]]化する`、`[[分析]]して` はすべて誤り。
- 「〜的」「〜する」が必要なら文を組み替える：

> 誤：`この時代は[[産業革命]]的な変化を…`
> 正：`この時代の変化をもたらしたのが[[産業革命]]です。`
> 誤：`**フランクリン・D・ローズヴェルト**は[[ニューディール政策（1933年）]]する。`
> 正：`**1932年**、**フランクリン・D・ローズヴェルト**が大統領に選ばれ、[[ニューディール政策（1933年）]]が
> 始まります。`

- 太字と重ねる場合は太字を外側に：`**[[第二次世界大戦]]**のさなか`。
- キーが文に合わないときは、文のほうを書き直す。キーは変えない。

## 5. 固有名詞

**人名は訳さない。** 機械翻訳は普通名詞として読んでしまう：Degas は `ドガ`、Munch は `ムンク`、
Corneille は `コルネイユ`（×カラス）。

**表記の原則。** 日本語版ウィキペディアの見出しと主要な辞典で定着した形に合わせる。
- 名と姓の間は中黒：`シャルル・ボードレール`、`クロード・モネ`、`フョードル・ドストエフスキー`。
- 長音は「ー」：`コンピューター`、`ローズヴェルト`。「ヴ」は定着している場合だけ（`ゴッホ`、
  `ヴェルサイユ`）。迷ったら一度決めて `scripts/proper_nouns.json` に登録し、全コースで統一する。
- フランス語の読みを優先：`Seurat` → `スーラ`、`Nadar` → `ナダール`、`Aupick` → `オーピック`。

**定着した日本語形**（コース全体で統一）：`Christophe Colomb` → `コロンブス`、`Londres` → `ロンドン`、
`Pékin` → `北京`、`Aix-la-Chapelle` → `アーヘン`、`Charlemagne` → `カール大帝`、`Michel-Ange` →
`ミケランジェロ`、`Saint-Pétersbourg` → `サンクトペテルブルク`、`Ulysse` → `オデュッセウス`、`ONU` →
`国連`、`OTAN` → `NATO`、`Byzance` → `ビザンツ`、`Sassanides` → `ササン朝`、`roi Arthur, reine
Guenièvre` → `アーサー王、グィネヴィア王妃`。ギリシア神話はギリシア語形で：ナルキッソス（花は
`スイセン`）、エコー（現象は `こだま`）、ダイダロス、イカロス、シシュポス、タンタロス、イアソン、
メデイア、ポリュペモス、クロノス、ヘシオドス、オリュンポス、テイレシアス、パーン、ネメシス。ロシア語：
ラスコーリニコフ、ソーニャ・マルメラードワ、ポルフィーリー・ペトローヴィチ。

**イスラームとアラビア語**：`ムハンマド`、`メッカ`、`メディナ`、`ヒジュラ`（`ヒジュラの後`）、`ウンマ`、
`カリフ`、`ジズヤ`、`ズィンミー`、`ジハード`、`ベドウィン`、`ムアッジン`。razzia は `略奪遠征`。
誤：`ヘジラ`、`マホメット`（現代の教材では使わない）、`ウマ`、`ラジア`。

**作品名は日本で定着した題名**で、直訳しない（完全な一覧：`oeuvres.json`）：

| フランス語 → 日本語 | フランス語 → 日本語 |

`*『草上の昼食』*`。定着した邦題がなければ原題をカタカナか原語で残し、初出で（）に説明を添える。

## 6. 引用

引用は翻訳の練習ではありません。定着した日本語訳があればそれを使い、なければ短く明快に訳す。

- かぎ括弧は「」、引用の中の引用は『』。`« »`、`" "`、`“ ”` は使わない：`**"Spleen et Idéal"**` →
  `**「憂鬱と理想」**`。
- 句点は閉じかっこの前に置かない：`「すべての動物は平等である」と書かれています。`。引用が独立した
  一文のときも `」` の直前に `。` を入れない（現代の出版・教材の慣行）。
- `quote.attribution` は `著者『作品名』`：`シャルル・ボードレール「万物照応」`。発言者を補うときは
  （）：`フョードル・ドストエフスキー『罪と罰』（ラスコーリニコフ）`。
- 『動物農場』の定訳的な一文：`「すべての動物は平等である。しかし、ある動物はほかの動物よりも
  もっと平等である」`。

## 7. 句読点と表記

- 句読点は全角の `、` `。` `？` `！` `：` `（）` を使う。半角の `,` `.` `?` `!` `(` は日本語の文中で使わない。
  `！` `？` は控えめに。
- **ダッシュ（`—`、`–`、`―`）は使わない。** 読点、コロン、（）、文の分割で書き直す。期間は
  `1945〜1975年`、`14〜16世紀`（`timeline` の日付とタイトルの年はフランス語どおり `1945-1975` を残す）。
- **空白を入れない。** 和文と英数字の間、句読点の前後、記号の前後に空白は不要：`Sophia Premiumで`
  （ブランド名内部の空白だけは残す）、`DNAの発見`、`25%`。全角空白、ゼロ幅文字、U+00A0、BOMは禁止。
- 中黒「・」は外国人名の区切りと並列の名詞だけ。三点リーダーは `…`（2つ並べて `……`）、`...` は不可。
- 漢字とかなの配分は常用漢字表に従い、中高生が読める程度に：`出来る` → `できる`、`事` → `こと`
  （形式名詞）、`様々` は可。難読語には言い換えを優先し、ルビは使わない。
- 外来語の普通名詞は定着していれば使ってよいが、和語・漢語で言えるなら優先：`パラダイムシフト` より
  `考え方の大転換`。
- フランス語の残骸（`siècle`、`l'`、`Salon des Refusés` のまま）や壊れた文字（`**Z69**%`、`Zの印象派`）は
  機械翻訳のゴミ。文ごと書き直す。

## 8. 数、日付、単位

- 数字は半角アラビア数字。漢数字は慣用表現だけ（`一度`、`二度と`、`第一次世界大戦`）。
- 大きな数は「万」「億」で：`10 000 hommes` → `1万人`、`30 000 mots` → `3万語`、`2,5 Mds` → `25億`。
  端数がある4桁以上はカンマ区切り：`12,480人`。小数点はピリオド：`3,5 %` → `3.5%`（`%` の前に空白なし）。
- **年**：`En 1857` → `**1857年**に`、`Vers 570` → `**570年**ごろ`、`dès 610` → `**610年**から`。
  `**1857**年` のように「年」を太字の外に出さない。
- **日付**は年月日の順：`**24 octobre 1929**, Wall Street s'effondre` → `**1929年10月24日**、
  ウォール街の株価が暴落します。` 範囲：`1954年3月13日から5月7日まで`；`entre 1945 et 1975` →
  `1945年から1975年にかけて`；`années 1850` → `1850年代`。
- **世紀**：`VIIe siècle` → `7世紀`、`XIVe-XVIe siècle` → `14〜16世紀`。ローマ数字は使わない。
- 紀元：`av. J.-C.` → `紀元前`（`紀元前399年`）、`apr. J.-C.` → 原則省略、必要なら `紀元後`。
  `BC`、`B.C.` は使わない。
- 年齢と期間：`à 25 ans` → `25歳で`（×`25年間`）、`en 22 ans` → `22年で`。単位の換算はしない
  （メートル法のまま）。時刻・カウントダウンは `02:59:59` の形を残す。
- `NIV. 3` → `レベル3`；`120 XP jusqu'au niveau 5` → `レベル5まであと120 XP`。

**複数形と助数詞。** 日本語に複数形はない。`%d quiz` / `%d quizzes` のような単数・複数の
キー（`.stringsdict` の `one` / `other`）は、すべて同じ形で埋める。複数を示す「たち」「ら」「々」を
機械的に足さない（`les pays` → `国々` ではなく文脈で `各国`、`51 pays` → `51か国`）。数には助数詞を付ける：

| 対象 | 形 | 例 |
| --- | --- | --- |
| クイズ | 〜件 | `%d件のクイズ`、`クイズ全%d件` |
| 問題・正解 | 〜問 | `%d問正解`、`bonnes réponses` → `正解数` |
| コース | 〜コース | `3コース修了` |
| レッスン | 〜回 | `全5回のレッスン` |
| 日数・連続記録 | 〜日 | `7日連続`、`Soit %@ complets.` → `つまり丸%@です。` |
| 人・国・詩・本 | 〜人、〜か国、〜篇、〜冊 | `6篇の詩`、`51か国` |
| 科目 | 〜科目 | `Tes 3 matières gratuites` → `無料で学べる3科目` |

## 9. 製品用語

アプリ全体で一つの形だけを使う。`sentinelles.json` に載っている文字列は `scripts/i18n_gate.py` が
一字ずつ照合するので、変えるなら同じコミットでそちらも更新し、理由を書く。

| フランス語 | 日本語（この形だけ） | 使わない |
| --- | --- | --- |
| Premium；Sophia Premium | プレミアム；製品名としては `Sophia Premium` | プレミア、有料版、Premium会員 |
| essai gratuit；Fin de l'essai | 無料トライアル；`無料トライアル終了` | 試用、お試し裁判、体験版 |
| Démarrer mon essai de {n} jours；Débloquer mon essai | `{n}日間の無料トライアルを始める`；`無料トライアルを始める` | 私の試用を解除 |
| abonnement；Mensuel / Annuel | サブスクリプション（月額プラン、年額プラン）；ラベルは `月額` / `年額` | 定期購読、月刊、年刊 |
| Offre de bienvenue；l'offre (paywall) | `ウェルカム特典`；`プラン`（`プランを読み込めませんでした`） | オファー、提案 |
| Expire dans | `終了まで` | 期限切れ、失効 |
| Annule à tout moment, sans frais. | `いつでも無料で解約できます。` | キャンセル料なし |
| série (streak) | 連続記録（`7日連続`） | ストリーク、シリーズ |
| XP；niveau, NIV. 3 | XP；レベル、`レベル3` | 経験値ポイント、段階 |
| quiz | クイズ（`%d件のクイズ`、`レベル%dのクイズ`） | テスト、小テスト、クイズたち |
| cours；leçon | コース；レッスン | 授業、講義、課程 |
| parcours；collection | 学習ルート；コレクション | 旅、道のり |
| Entraînement；réviser | トレーニング；復習する（ボタン `復習`） | 練習問題、見直し |
| glossaire；Bibliothèque；Accueil | 用語集；ライブラリ；ホーム | 辞書、図書館、家 |
| matière / sujet；objectif | 科目 / テーマ；目標 | 物質、対象；レンズ |
| débloquer | 解放する（`プレミアムで解放`） | ロック解除する |
| notification；progression；terminé | 通知；進み具合（グラフは `教養の伸び`）；完了 | お知らせ、進歩 |
| Vrai / Faux | 正しい / まちがい（設問：`正しい？まちがい？`） | 真 / 偽、本当 / 嘘 |
| culture；cultivé | 教養；教養が身につく（`1日10分で教養が身につく`） | 文化的になる |
| Pas de connexion. Vérifie ton réseau et réessaie. | `接続されていません。ネットワークを確認して、もう一度お試しください。` | |
| bloqueur TikTok；ambassadeur | TikTokブロッカー；アンバサダー | 大使 |

App Storeページは同じ用語で、です・ます調、誇張表現（「最強」「完全無料」）は使わない。規約類は
「本サービス」「利用者」を用い、法的な意味を変えない。迷ったら原文の範囲で控えめに訳す。

## 10. チェックリスト

```bash
python scripts/check_course_translation.py --lang ja
python scripts/check_course_translation.py --lang ja course_102_*
python scripts/i18n_gate.py
```

検査は骨格のずれ、壊れた記号、用語の数、未登録のキー、末尾に追いやられた用語、禁止文字、空白、
フランス語の残骸、ローカライズされていない数を報告します。エラーゼロは努力目標ではなく義務です。
検査が見ない誤りは手で探す：

```bash
grep -rnE 'あなた|君は|私たちは|彼らは言|[—–―]|«|»|"|\[\[[^]]*\]\](的|化|する)|[ 　]\[\[|\]\][ 　]|[0-9]+ ?年間で|紀元前 |[、。]\s' content/courses/ja/
```

最後に声に出して読む：

- [ ] です・ます調で統一、見出しとボタンは体言止め、「あなた」なし。
- [ ] `on` を「私たち」「彼ら」にしていない。
- [ ] プレースホルダーの数と順序が原文と同じ、前後に空白なし。
- [ ] `**` と `*` が対になり、作品名は `*『…』*`、助詞は記号の外。
- [ ] `[[…]]` はキーそのもの、文中の正しい位置、助詞だけが直後に続く。
- [ ] 人名・地名・作品名は定着した日本語形、`proper_nouns.json` と一致。
- [ ] 「」と『』、全角句読点、ダッシュなし、空白なし。
- [ ] 数は半角、万・億、`年月日`、`世紀`、`紀元前`、助数詞付き。
- [ ] 製品用語は§9の形だけ、`sentinelles.json` と一致。
