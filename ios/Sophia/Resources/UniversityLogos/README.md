Logos des universités affichés sur la page « profs certifiés » de l'onboarding.

Dépose ici des PNG nommés `university_<nom>.png` (fond transparent, ~400 px de large,
logo sombre ou monochrome de préférence). La page les charge tous automatiquement,
dans l'ordre alphabétique du nom de fichier ; rien d'autre à faire.
