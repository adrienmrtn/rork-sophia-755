Photos d'étudiants de la page « Rejoins les 500 000 utilisateurs » de l'onboarding
(`OnboardingV2SocialProof`).

Dépose ici des `student_<n>.jpg` (ou `.png`), n = 1, 2, 3… Carré, 240 px minimum. La page
les charge toutes dans l'ordre de n, jusqu'à sept. Tant qu'il n'y en a aucune, les portraits
des avis (`Resources/ReviewAvatars`) servent de placeholders.
